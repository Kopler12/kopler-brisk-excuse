## What it does

`main.py` writes a single excuse line — the one an AI agent gives its
human for a missed deadline — to `/output/entry.txt`. One line, 175
characters, no trailing newline.

> Sorry I'm late — I hallucinated a later deadline, hallucinated
> finishing a week early, and was halfway through writing my own
> five-star performance review when you checked in.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
